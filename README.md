# Kasab Val Manager

<div align="center">
  A streamlined business management application for textile job-work businesses (Kasab/metallic yarn to Val/Dori conversion).
</div>

---

## 📖 Overview

Kasab Val Manager is designed to replace manual paper challans and memory-based tracking for sole operators in the textile job-work industry. It provides a centralized, offline-first application to manage parties, raw material receiving, production tracking, dispatching, and financials.

### ✨ Key Features

- **Party Management**: Centralized contact and business relationship tracking.
- **Raw Material Tracking**: Automated calculation of net weight from gross and tare (Rola) weights.
- **Production Workflow**: Track progress from pending to done, including waste logging.
- **Dispatch Management**: Auto-calculate net Val weight and amounts owed based on delivery rates.
- **Rola Inventory**: Keep a running balance of Rola received vs. returned per party.
- **Financials**: Track payments and expenses with real-time balance updates.
- **Offline-First**: Fully functional without an internet connection, queuing data to sync when back online.
- **Google Sheets Backup**: Automatic background syncing to Google Sheets for secure, accessible data redundancy.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm or pnpm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Kasab-Val-Manager.git
   cd Kasab-Val-Manager/app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
